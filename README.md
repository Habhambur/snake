Repository pada dasarnya adalah tempat penyimpanan digital untuk seluruh berkas proyek atau aplikasimu.
Di dalam repo ini, kamu bisa menyimpan semua file , folder proyek, sampai ke track record atau sejarah
setiap kali kamu melakukan perubahan dari awal buat sampai sekarang.  

fungsi
1. Penyimpanan Kode Terpusat :Menyimpan semua berkas dan dokumen proyekmu di satu wadah yang rapi, terstruktur, dan pastinya aman.
2. Mencatat Riwayat Perubahan :Melacak siapa yang ngubah file, kapan diubahnya, dan bagian mana yang ditambah atau dihapus. Kalau kodenya 
                            mendadak error, kamu bisa dengan gampang memutar balik kodenya ke versi terdahulu yang masih aman.   
3. Wadah Kolaborasi Bareng Tim :Bikin kamu dan teman-teman timmu bisa garap satu proyek yang sama secara barengan tanpa takut kodenya
                                 bentrok atau saling menimpa, memanfaatkan fitur branch dan pull request.
4. Dokumentasi & Etalase Portofolio Proyek: Menjelaskan gambaran aplikasi, cara install, dan cara pakainya ke orang lain lewat file README.md,
                                            sekaligus jadi wadah buat mamerin hasil kodinganmu ke perekrut kerja atau komunitas.
